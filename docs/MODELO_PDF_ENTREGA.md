## Resumo do projeto

A Calculadora Inteligente de Obras é uma aplicação web criada para auxiliar no planejamento inicial de obras. O sistema calcula a área de uma parede, estima a quantidade de tijolos necessários e adiciona uma margem de perda de 10%.

Nesta etapa intermediária, a aplicação foi evoluída com integração à API pública ViaCEP, permitindo consultar automaticamente o endereço da obra a partir do CEP informado pelo usuário.

## Dor real atendida

O projeto busca apoiar pequenos profissionais, estudantes e clientes que precisam estimar materiais de construção de forma rápida, simples e organizada. A aplicação ajuda a reduzir erros básicos de cálculo e agiliza o preenchimento de informações da obra.
