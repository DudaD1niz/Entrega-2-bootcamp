# Título da Issue

Integração com API ViaCEP e publicação da aplicação web

# Descrição da Issue

Adicionar uma nova funcionalidade à Calculadora Inteligente de Obras para consultar automaticamente o endereço da obra por meio da API pública ViaCEP.

A funcionalidade permitirá que o usuário informe o CEP e receba logradouro, bairro, cidade e UF diretamente na interface web.

Objetivos:

- Consumir uma API REST pública.
- Exibir os dados retornados na interface.
- Criar teste automatizado para validar o fluxo.
- Manter o GitHub Actions funcionando.
- Publicar a aplicação em um link público.
