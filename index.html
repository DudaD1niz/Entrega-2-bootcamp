Calculadora Inteligente de Obras

Uma aplicação web para apoiar pequenos profissionais e clientes no planejamento inicial de obras, calculando materiais e buscando automaticamente o endereço da obra por CEP.

Sistema web com integração ViaCEP

Dados da parede

Informe as medidas e o CEP da obra para gerar uma estimativa inicial.

O endereço será exibido após a consulta do CEP na API ViaCEP.

Dor real atendida

A aplicação ajuda no planejamento básico de obras, reduzindo erros de cálculo e agilizando o preenchimento de endereço por meio de uma API pública.

API utilizada

A integração usa a API ViaCEP para consultar logradouro, bairro, cidade e UF a partir do CEP informado.

Entrega contínua

O projeto contém teste automatizado e workflow de GitHub Actions para validar o fluxo antes da entrega.
